# UI design system

## Thesis

A calm financial bridge from ambition to a concrete next step. Deep forest navigation, warm stone canvas, precise tabular figures, saffron milestones, and an original connected interface diagram distinguish the brand.

## Tokens

Forest #123E32, emerald #17674F; saffron #DAA452; ink #192E29; muted #62736D; border #DDE4DE; stone #F7F8F4; paper #FFFFFF; teal info #236B81; error #A33F3F. No claim of government endorsement.

Typography: locally served Inter with Noto Sans Devanagari fallback. Display 56/1.1 desktop, 36 mobile; H1 36, H2 26, H3 20; body 16/1.6; labels 14; metadata 12–13. Financial numbers use tabular numerals. Hindi uses generous line height.

Spacing: 4/8/12/16/24/32/48/64/96px. Radius: inputs 8, cards 14, feature panels 20; pills reserved for status. Shadows: subtle 0 8px 28px rgba(20,50,40,.06). Borders define structure without over-boxing content.

## Behavior

44px minimum controls; clear focus outline with offset; 160ms hover transitions; 240ms page entry. Reduced-motion disables decorative animation. Loading skeletons preserve layout; matching shows a brief staged process while actual API work runs. Errors use actionable inline messages; toasts announce completed mutations. Empty states include one useful next action.

## Layout

Mobile first: one column at 360–639px; two at 768; sidebar at 1024; max content width 1240. Landing has asymmetric narrative and interface visual. Dashboards have forest sidebar and a quiet top bar; recommendation has financial summary followed by evidence. Mobile navigation wraps and collapses without horizontal overflow. Tables use labelled scroll regions. Simple mode enlarges text/controls and hides secondary explanatory density, preserving actions.

## Review

Inspect landing, onboarding, results, schemes, comparison, EMI, documents, partners, application review/tracking, login and role dashboards at desktop and mobile. Verify keyboard focus, form labels, state feedback and language changes.
