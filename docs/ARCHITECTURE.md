# Architecture

Next.js/React frontend → same-origin /api proxy → Express API → Mongoose/MongoDB. Shared TypeScript domain types and pure engines prevent contradictory calculations. Backend is authoritative for eligibility, ranking, application creation, identity and transitions. Local demo uses a real MongoDB process with persistent database files when no external MongoDB URI is configured; production requires managed MongoDB and HTTPS.

Opaque random sessions are stored hashed in MongoDB; bcrypt passwords; HTTP-only SameSite cookies; role and record ownership checks. Origin validation, rate limits, Helmet, Zod input validation, sanitized errors and append-only audit records protect mutations. No role is trusted from browser state.

Schemes reference an active immutable approved version. Draft changes require an explicit approval operation; prior versions are retained. Evaluations and applications keep the rule version used. Financial estimates use reducing-balance EMI, explicit moratorium treatment and rounded presentation only.

AI is downstream of deterministic results: structured profile → rules → ranked result → explanatory context → templated English/Hindi explanation. Optional external AI never changes eligibility. Mapping uses OSM/Leaflet with seeded coordinates; network loss must leave the partner list usable.
